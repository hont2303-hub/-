# 第1章：育児の隙間時間でも回る副業の仕組み

## 「まとまった時間ができたらやろう」が一番危険です

3人の子供がいる私に言わせれば、まとまった時間は永遠に来ません。
生後1ヶ月の三男は3時間おきに泣きます。
長男の宿題を見ながら、次男の相手もしなければなりません。

だから、「まとまった時間」ではなく「細切れの時間」で動く仕組みを作りました。

## 1日の隙間時間の使い方

**朝の車通勤**
Claude Codeに「今週書く記事のテーマを10個提案して」と音声で入力します。
信号待ちや到着後に結果を確認するだけです。

**昼休み（15〜20分）**
テーマを選んで、記事の骨格をClaude Codeに作らせます。
確認するだけで完了します。

**夜（子供が寝た後・30〜60分）**
骨格をもとに各セクションの本文を生成します。
自分の体験・数字・感情を書き加えます。

このサイクルで、1記事が2〜3日で完成します。

## 大切なのは「考える作業」と「書く作業」の分離です

考える作業（テーマ・構成）はClaude Codeに任せます。
書く作業（自分の体験を足す）だけに集中します。

この分け方が、時間がない人の副業を成立させる核心です。

# 第2章：Claude Codeで売れるテーマを見つける方法

## 最初の2ヶ月ゼロ円だった理由

最初の2ヶ月、私は「書きたいことを書いていました」。

・Claude Codeの使い方まとめ
・AIで業務効率化する方法

どれも売れませんでした。

理由はシンプルです。「自分が書きたいこと」と「読者が知りたいこと」がずれていました。

## テーマはClaude Codeに分析させます

毎週月曜の朝、このプロンプトを使っています。

```
あなたはnote.comのコンテンツマーケターです。

以下の条件でバズるテーマを10個提案してください。

【私のプロフィール】
・31歳・地方ゼネコン勤務の会社員
・3人の子育て中・隙間時間で副業
・Claude Codeを使ったnote副業が得意

【条件】
・「会社員が実体験で書いた」感が出るタイトル
・有料記事（980〜1,980円）として成立する深さ
・「時間がない人」「家族がいる人」が共感できる内容

各テーマについて：
1. タイトル案（3パターン）
2. 想定読者
3. この記事が売れる理由
4. 目次案（5〜7項目）
```

10個の提案から「自分が体験ベースで書けるもの」を選びます。
それだけでテーマ選定は終わります。

## テーマ選定の判断基準は3つです

**① 自分が実体験で書けるか**
体験がないテーマは薄くなります。「試したことがある」レベルが最低ラインです。

**② 悩んでいる人が明確か**
「子育て中の会社員がAI副業で稼ぐ方法」→ 悩んでいる人が想像できます ◯
「AIの未来について」→ 誰が悩んでいるかわかりません ✕

**③ 有料にして当然の情報量があるか**
手順・数字・プロンプト・失敗談がセットで出せるテーマを選びます。

# 第3章：1記事3時間で仕上げる執筆フロー

## なぜ3時間で書けるのか

育児がある私に6時間の作業時間はありません。
作業の8割をClaude Codeに任せ、残り2割に自分の体験を足す方法にしました。

## Phase 1（30分）：骨格をClaude Codeに作らせます

```
以下のテーマで売れるnote記事の骨格を作ってください。

テーマ：[テーマ名]
想定読者：[読者像]
文字数：5,000字程度

出力してほしいもの：
1. タイトル（3案）
2. リード文（300字）
3. 目次（6〜8項目・各項目に「なぜ必要か」1行で）
4. 各セクションの要点（箇条書き3〜5点）
5. まとめと読者への問いかけ
```

## Phase 2（60分）：セクションごとに本文を生成します

```
以下のセクションの本文を書いてください。

セクション名：[第○章のタイトル]
要点：[Phase 1の箇条書き]
文字数：800〜1,000字
トーン：子育て中の会社員が語りかける口調。丁寧に、でも親しみやすく。
必ず含めてほしいもの：具体的な数字・読者への問いかけ・アクション可能な手順
```

## Phase 3（60分）：自分の言葉を重ねます

AIが生成した文章に、自分だけの情報を足します。

- **数字**：「先月10部売れました」
- **失敗談**：「最初の2ヶ月はゼロでした」
- **感情**：「初めて売れたとき、素直に嬉しかったです」

読者は情報ではなく、あなたの経験を買います。
この2割が、売れる記事と売れない記事の差です。

## Phase 4（30分）：編集・仕上げをします

```
以下の記事を編集してください。

観点：
1. 冗長な表現を削除（1文40字以内を目安に）
2. 読みやすい文末に統一する
3. 「一番伝えたいこと」が冒頭300字に凝縮されているか確認
4. 最後のセクションで読者が次のアクションを取りやすいよう強化

優先順位：読みやすさ > 情報量 > 完璧な文法
```

# 第4章：Threadsでフォロワーを増やしてnoteに誘導する設計

## フォロワー14人でも売れた理由

現在、私のThreadsフォロワーは14人です。

それでも有料記事が10部売れました。

理由は「フォロワーの数」より「プロフィールの設計」が機能したからです。

ただ、フォロワーが増えれば同じ設計でもっと売れます。
だから今、フォロワー1,000人を最優先で目指しています。

## 最速の方法はリプ返信です

Threadsで最速にフォロワーを増やす方法は、投稿を増やすことではありません。

他の人の投稿のリプ欄に、自分の体験を書くことです。

**1日10分のルーティン**
① 「副業」「AI副業」「子育て副業」で検索します
② 最新投稿5件のリプ欄に自分の体験を1〜2文で返信します
③ 返信してきた人には必ず返します

「私も3人の子育て中です。同じ状況から始めました」

この一言が、フォロワーへの入口になります。

## 1,000人達成後はプロフィールで誘導します

投稿では宣伝しません。プロフィールだけにリンクを置きます。

```
【名前】ゆうき｜AI副業会社員
【一言】3人の子育て中・新潟のゼネコン勤務
　　　 → Claude Codeで有料記事10部販売
【リンク】↓ 隙間時間で副業する全手順（980円・値上げ予定）
```

「3人の子育て中」という一言が、同じ状況の読者に刺さります。

## フォロワー数別のやることリスト

| フォロワー数 | やること | やらないこと |
|---|---|---|
| 0〜300人 | リプ返信に集中・自己投稿は週3〜4回 | noteの宣伝 |
| 300〜1,000人 | 投稿の質を上げる・プロフィール最適化 | 毎投稿でリンクを貼る |
| 1,000人〜 | 週1回だけnote記事をさりげなく紹介 | 焦って売ろうとする |
