# 第1章：15分で終わる環境構築｜黒い画面への恐怖を消す

## なぜここから始めるのか

Claude Codeはブラウザで動くツールではない。自分のパソコンに「作業環境」を作る必要がある。

「黒い画面（ターミナル）」「コマンド入力」という言葉で9割の人が止まる。でも逆にいえば、ここを超えれば競合が一気に減る。

手順は3つだけ。所要時間は15〜30分。一度やれば二度とやらなくていい。

## 具体的な手順（Windows・Mac共通）

### Step 1：Node.jsをインストールする

Claude Codeを動かすために必要なソフトウェア。

1. ブラウザで `nodejs.org` にアクセス
2. 「LTS（推奨版）」をクリックしてダウンロード
3. インストーラーを起動し、全て「Next」で進める
4. 確認：ターミナルで `node -v` と入力 → バージョン番号が出ればOK

**Windowsの注意点：** PowerShellではなく「コマンドプロンプト」を使うとトラブルが少ない。

### Step 2：Claude Codeをインストールする

ターミナルを開き、以下の1行を入力してEnterを押す。

```
npm install -g @anthropic-ai/claude-code
```

これだけだ。「最強の部下」があなたのPCに配属される。

### Step 3：Anthropicのアカウントを作る

1. `claude.ai` でアカウント作成（無料）
2. Proプラン（月$20 ≒ 約3,000円）に登録する

**Proプランが必要な理由：**
無料版ではClaude Codeが使えない。ただ、月3,000円は副業の初期投資として考えよう。1記事980円が4部売れれば元が取れる。

### 動作確認

ターミナルで `claude` と入力してEnterを押す。ログイン画面が出てきたらサインイン完了。

試しにこう入力してみよう：

```
日本語で100字の自己紹介文を書いて
```

数秒で文章が生成されれば、準備は完了だ。

# 第2章：「何を書けばいいか」をClaude Code自身に分析させる

## 副業初心者が最初につまずく「テーマ選定」

「書きたいことを書く」は副業では通用しない。売れるのは「誰かが今、困っていること」を解決するコンテンツだけだ。

でも、「何が売れるか」を自分で調べるのは時間がかかる。だからClaude Codeに任せる。

## 実際に使っているテーマ分析プロンプト

毎週月曜日の朝に実行しているプロンプトがこれだ。

```
あなたはnote.comのコンテンツマーケターです。

以下の条件でバズるテーマを10個提案してください。

【私のプロフィール】
- 会社員（30代・非エンジニア）
- Claude Codeを使った副業・業務効率化が得意
- 月5万円の副収入実績あり

【条件】
- 「会社員が実体験で書いた」感が出るタイトル
- 有料記事（980〜1,980円）として成立する深さ
- 検索されやすいキーワードを含む

各テーマについて：
1. タイトル案（3パターン）
2. 想定読者
3. この記事が売れる理由
4. 目次案（5〜7項目）

を出力してください。
```

10個の提案が出てくる。その中から「自分が体験ベースで書けるもの」を3〜5個選んで、その週の執筆リストにする。

## テーマ選定の3つの判断基準

**① 自分が実体験で書けるか**
体験ゼロのテーマは薄くなる。最低でも「試したことがある」レベルが必要だ。

**② 検索需要があるか**
Googleで「[テーマ] 方法」と検索してみる。検索結果が10件以上あれば需要がある証拠。

**③ 有料にして当然の情報量があるか**
無料ブログで書けるレベルなら売れない。「具体的な手順・数字・プロンプト・失敗談」がセットで提供できるテーマを選ぶ。

# 第3章：80:20法則で1記事を3時間で仕上げる

## 会社員の副業における最大の敵は「時間のなさ」

「良い記事を書こう」と思ったとき、多くの人は0から書き始める。これでは6〜8時間かかる。

**80:20法則を使う。**

作業の8割はClaude Codeに任せ、残り2割に自分の経験・数字・感情を足す。これで品質を落とさず、作業時間を半分以下にできる。

## 3時間執筆フロー（全手順）

### Phase 1（30分）：骨格をClaude Codeに作らせる

```
以下のテーマで売れるnote記事の骨格を作ってください。

テーマ：[テーマ名]
想定読者：[読者像]
記事の目標：[読者が得るもの]
文字数：5,000字程度

出力してほしいもの：
1. タイトル（3案）
2. リード文（300字）
3. 目次（6〜8項目・各項目に「なぜ必要か」を1行で）
4. 各セクションの要点（箇条書き3〜5点）
5. まとめと読者への問いかけ
```

### Phase 2（60分）：本文をセクションごとに書かせる

骨格ができたら、セクションごとに本文を生成する。一度に全部頼むと品質が落ちる。

```
以下のセクションの本文を書いてください。

セクション名：[第○章のタイトル]
要点：[Phase 1で出てきた箇条書き]
文字数：800〜1,000字
トーン：実体験を持つ会社員が語りかける口調。断定的に、でも温かく。
必ず含めてほしいもの：具体的な数字・読者への問いかけ・アクション可能な手順
```

### Phase 3（60分）：自分の言葉を重ねる

AIが書いた文章に、自分だけが持っている情報を書き加える。

- **数字**：「この方法で3件目の受注が来た」
- **失敗談**：「最初はこのステップを飛ばして1週間詰まった」
- **感情**：「初めて有料記事が売れた朝の感覚は今でも覚えている」

この「自分だけが書けること」が、AIが書いた記事との差別化になる。読者は情報ではなく、**あなたの経験**を買う。

### Phase 4（30分）：編集・仕上げ

```
以下の記事を編集してください。

【観点】
1. 冗長な表現を削除（1文は短く。40字以内を目安に）
2. 体言止めを活用して読みやすくする
3. 「この記事で一番伝えたいこと」が冒頭300字に凝縮されているか確認
4. 読者が次のアクションを取りやすいよう、最後のセクションを強化

【優先順位】
読みやすさ > 情報量 > 完璧な文法
```

# 第4章：Threadsを使った「読まれる導線」の設計術

## なぜThreadsが今、最強の集客装置なのか

XとInstagramとThreads。この3つの中で、**今一番コスパよく読者を集められるのはThreadsだ。**

理由は3つある。

**① アルゴリズムが新参者に優しい**
Xは古いアカウントほど有利だ。Threadsはまだ成長途中のプラットフォームで、フォロワー数が少なくても良い投稿は拡散される。

**② テキストの長さが強みになる**
Xは140字の制約がある。Threadsは長文でも読まれる文化がある。「体験談・本音・失敗談」を500字で書けば、それ自体がコンテンツになる。

**③ noteとの親和性が高い**
Threadsのユーザー層は「文章を読むのが好きな人」が多い。note有料記事の購入者層とほぼ一致する。

## Threads→note→購入の「導線」を設計する

重要なのは、Threadsを「宣伝の場」ではなく「信頼を積む場」として使うことだ。

多くの人が間違えるのはここだ。投稿するたびに「noteを読んでください」と言う。それでは誰もフォローしない。

**正しい導線はこうだ。**

```
① Threadsで「価値ある体験談」を毎日投稿する
      ↓（信頼・共感が積み上がる）
② フォロワーが増え、投稿がリーチする
      ↓（興味を持った人がプロフィールを見る）
③ プロフィールにnoteリンクを貼る
      ↓（記事の無料部分を読む）
④ 「続きが読みたい」と思った人が980円を払う
```

宣伝ゼロで売れる構造だ。

## Threadsで使える投稿パターン3つ

### パターン①：「数字で語る体験談型」（拡散されやすい）

```
副業3ヶ月目で月5万円を超えた。

内訳を公開する。
・有料記事（980円）：31部 → 30,380円
・クラウドソーシング：2件 → 21,600円
合計：51,980円

1ヶ月目はゼロだった。
2ヶ月目で1万円。
3ヶ月目で5万円を越えた。

何が変わったか。
「書きたいこと」を書くのをやめた。
「誰かが困っていること」だけを書くようにした。

それだけ。

#AI副業 #ClaudeCode
```

**なぜ効くか：** 数字がリアルで信頼感がある。「自分もできるかも」と思わせる展開。

### パターン②：「気づき・学び型」（保存されやすい）

```
Claude Codeを3ヶ月使って気づいたこと。

ChatGPTとの決定的な違いは「自律性」だ。

ChatGPT：指示した通りに動く
Claude Code：ファイルを読んで、次にやるべきことまで提案してくれる

つまり、ChatGPTは「優秀な部下」
Claude Codeは「仕事を理解した右腕」

この差が、副業収益に直結した。

詳しい話はnoteに書いています（プロフィールのリンクから）

#ClaudeCode #AI副業
```

**なぜ効くか：** 「なるほど」と思わせる比較軸。保存・シェアされやすい。

### パターン③：「問いかけ型」（コメントが来やすい）

```
会社員が副業で一番つまずく場所、知ってますか？

「やり方がわからない」じゃなくて
「何をやればいいかわからない」なんですよね。

私も最初の2ヶ月はここで詰まった。

これを解決したのが、Claude Codeに「売れるテーマを分析させる」方法だった。

あなたは副業を始めようとして、どこで詰まりましたか？

#副業 #AI副業
```

**なぜ効くか：** コメントが来るとアルゴリズムに評価される。読者の悩みも同時にリサーチできる。

## 投稿スケジュールの設計

毎日投稿するのが理想だが、会社員には現実的でない場合もある。最低限これだけは守ろう。

| 曜日 | 投稿内容 | 目的 |
|---|---|---|
| 月・水・金 | 体験談型（数字あり） | 信頼構築・拡散 |
| 火・木 | 気づき型 | 保存・フォロー増加 |
| 土 | note記事公開の告知 | 流入・収益 |
| 日 | 問いかけ型 | コメント獲得・リサーチ |

**土曜日だけ告知する理由：** 毎日宣伝するとフォローを外される。週1回・自然な流れで誘導するのが鉄則だ。

## Threads告知文のつくり方（Claude Codeに任せる）

note記事を公開したら、すぐにClaude Codeに告知文を作らせる。

```
以下のnote記事をThreadsで告知する投稿文を作ってください。

記事タイトル：[タイトル]
記事の無料部分の要点：[3点箇条書き]
有料部分で得られること：[2〜3点]

Threadsの特徴：
- 200〜500字が最適
- 体験談・本音が拡散されやすい
- 最後に問いかけを入れるとコメントが来やすい
- ハッシュタグは2〜3個
- 「noteを読んでください」という直接的な宣伝文は避ける

3パターン提案してください。
```

3パターンの中から一番「自分らしい」ものを選んで、少し言葉を直して投稿する。これだけで告知文は完成だ。

# 第5章：図解・構造化で「有料にして当然」のコンテンツにする

## なぜ図解が売れる記事を作るのか

同じ情報量の記事が2つあるとき、人は必ず「図解あり」のほうを選ぶ。

視覚的にわかりやすい記事は「ちゃんと考えて作られている」という信頼感を生む。その信頼感が、Threadsで興味を持ち、無料部分を読み、980円を払う——という流れの最後の一押しになる。

## Claude Codeで図解のアイデアを出す

```
以下の記事の内容を図解するとしたら、どんな図解が効果的ですか？

[記事の目次または本文の概要]

以下の形式で提案してください：
1. 図解のタイトル
2. 図解の種類（フローチャート/比較表/ステップ図/マトリックス）
3. 図解に含める要素（5〜7項目）
4. この図解がなぜ読者の理解を助けるか
```

## 私が使っている図解パターン3つ

**① Before/After比較図**
「Claude Codeを使う前／後」の変化を視覚化する。読者が「3ヶ月後の自分」をイメージしやすくなる。

**② ステップ図（左から右へ）**
手順を横並びに表示。「今自分はどこにいるか」が一目でわかり、挫折率が下がる。

**③ 収益モデル図**
「1記事×単価×月間販売数 ＝ 月収」を視覚化。具体的な数字が入ると信頼度が跳ね上がる。

## 図解の作り方（コスト0円）

無料ツール「Canva」を使う。

1. Canvaでアカウント作成（無料）
2. 「インフォグラフィック」テンプレートを選択
3. Claude Codeが提案した要素を当てはめる
4. PNG形式でダウンロードしてnoteに貼り付ける

1つの図解を作るのに15〜20分。この手間が記事の「見た目の価値」を2倍にする。
