# 第1章：15分で終わる環境構築｜黒い画面への恐怖を消す

## なぜここから始めるのか

Claude Codeはブラウザで動くツールではない。自分のパソコンに「作業環境」を作る必要がある。

「黒い画面（ターミナル）」「コマンド入力」という言葉で9割の人が止まる。でも逆にいえば、ここを超えれば競合が一気に減る。

手順は3つだけ。所要時間は15〜30分。一度やれば二度とやらなくていい。

## 具体的な手順（Windows・Mac共通）

### Step 1：Node.jsをインストールする

Claude Codeを動かすために必要なソフトウェア。

1. ブラウザで `nodejs.org` にアクセス
2. 「LTS（推奨版）」をクリックしてダウンロード
3. インストーラーを起動し、全て「Next」で進める
4. 確認：ターミナルで `node -v` と入力 → バージョン番号が出ればOK

**Windowsの注意点：** PowerShellではなく「コマンドプロンプト」を使うとトラブルが少ない。

### Step 2：Claude Codeをインストールする

ターミナルを開き、以下の1行を入力してEnterを押す。

```
npm install -g @anthropic-ai/claude-code
```

これだけだ。「最強の部下」があなたのPCに配属される。

### Step 3：Anthropicのアカウントを作る

1. `claude.ai` でアカウント作成（無料）
2. Proプラン（月$20 ≒ 約3,000円）に登録する

**Proプランが必要な理由：**
無料版ではClaude Codeが使えない。ただ、月3,000円は副業の初期投資として考えよう。1記事980円が4部売れれば元が取れる。

### 動作確認

ターミナルで `claude` と入力してEnterを押す。ログイン画面が出てきたらサインイン完了。

試しにこう入力してみよう：

```
日本語で100字の自己紹介文を書いて
```

数秒で文章が生成されれば、準備は完了だ。

# 第2章：「何を書けばいいか」をClaude Code自身に分析させる

## 副業初心者が最初につまずく「テーマ選定」

「書きたいことを書く」は副業では通用しない。売れるのは「誰かが今、困っていること」を解決するコンテンツだけだ。

でも、「何が売れるか」を自分で調べるのは時間がかかる。だからClaude Codeに任せる。

## 実際に使っているテーマ分析プロンプト

毎週月曜日の朝に実行しているプロンプトがこれだ。

```
あなたはnote.comのコンテンツマーケターです。

以下の条件でバズるテーマを10個提案してください。

【私のプロフィール】
- 会社員（30代・非エンジニア）
- Claude Codeを使った副業・業務効率化が得意
- 月5万円の副収入実績あり

【条件】
- 「会社員が実体験で書いた」感が出るタイトル
- 有料記事（980〜1,980円）として成立する深さ
- 検索されやすいキーワードを含む

各テーマについて：
1. タイトル案（3パターン）
2. 想定読者
3. この記事が売れる理由
4. 目次案（5〜7項目）

を出力してください。
```

10個の提案が出てくる。その中から「自分が体験ベースで書けるもの」を3〜5個選んで、その週の執筆リストにする。

## テーマ選定の3つの判断基準

**① 自分が実体験で書けるか**
体験ゼロのテーマは薄くなる。最低でも「試したことがある」レベルが必要だ。

**② 検索需要があるか**
Googleで「[テーマ] 方法」と検索してみる。検索結果が10件以上あれば需要がある証拠。

**③ 有料にして当然の情報量があるか**
無料ブログで書けるレベルなら売れない。「具体的な手順・数字・プロンプト・失敗談」がセットで提供できるテーマを選ぶ。

# 第3章：80:20法則で1記事を3時間で仕上げる

## 会社員の副業における最大の敵は「時間のなさ」

「良い記事を書こう」と思ったとき、多くの人は0から書き始める。これでは6〜8時間かかる。

**80:20法則を使う。**

作業の8割はClaude Codeに任せ、残り2割に自分の経験・数字・感情を足す。これで品質を落とさず、作業時間を半分以下にできる。

## 3時間執筆フロー（全手順）

### Phase 1（30分）：骨格をClaude Codeに作らせる

```
以下のテーマで売れるnote記事の骨格を作ってください。

テーマ：[テーマ名]
想定読者：[読者像]
記事の目標：[読者が得るもの]
文字数：5,000字程度

出力してほしいもの：
1. タイトル（3案）
2. リード文（300字）
3. 目次（6〜8項目・各項目に「なぜ必要か」を1行で）
4. 各セクションの要点（箇条書き3〜5点）
5. まとめと読者への問いかけ
```

### Phase 2（60分）：本文をセクションごとに書かせる

骨格ができたら、セクションごとに本文を生成する。一度に全部頼むと品質が落ちる。

```
以下のセクションの本文を書いてください。

セクション名：[第○章のタイトル]
要点：[Phase 1で出てきた箇条書き]
文字数：800〜1,000字
トーン：実体験を持つ会社員が語りかける口調。断定的に、でも温かく。
必ず含めてほしいもの：具体的な数字・読者への問いかけ・アクション可能な手順
```

### Phase 3（60分）：自分の言葉を重ねる

AIが書いた文章に、自分だけが持っている情報を書き加える。

- **数字**：「この方法で3件目の受注が来た」
- **失敗談**：「最初はこのステップを飛ばして1週間詰まった」
- **感情**：「初めて有料記事が売れた朝の感覚は今でも覚えている」

この「自分だけが書けること」が、AIが書いた記事との差別化になる。読者は情報ではなく、**あなたの経験**を買う。

### Phase 4（30分）：編集・仕上げ

```
以下の記事を編集してください。

【観点】
1. 冗長な表現を削除（1文は短く。40字以内を目安に）
2. 体言止めを活用して読みやすくする
3. 「この記事で一番伝えたいこと」が冒頭300字に凝縮されているか確認
4. 読者が次のアクションを取りやすいよう、最後のセクションを強化

【優先順位】
読みやすさ > 情報量 > 完璧な文法
```

# 第4章：Threadsで1,000フォロワーを作り、noteに自然に誘導する

## まず「1,000フォロワー」を目標にする理由

Threadsで副業収益を作ろうとするとき、最初からnoteの宣伝をしても売れない。

フォロワーが少ない状態でリンクを貼っても、誰も見ていないからだ。

**最初の目標はたった一つ。フォロワー1,000人。**

1,000人いれば、1回の投稿が確実に数百人に届く。その中に「この人の記事を読みたい」と思う人が必ず出てくる。そこで初めて、noteへの導線が機能し始める。

逆にいえば、フォロワー1,000人未満のうちは「売ること」を考えなくていい。「信頼を積むこと」だけに集中する。

## フォロワーを増やす最速の方法は「リプ欄への返信」

多くの人は「良い投稿をすれば増える」と思っている。半分正解で、半分間違いだ。

Threadsのアルゴリズムは**「会話が生まれているアカウント」を優遇する。**

つまり、自分が投稿するだけでなく、**他の人の投稿のリプ欄（コメント欄）に積極的に返信することが、最速でフォロワーを増やす方法**だ。

### 効果的なリプ返信の3つのルール

**① 「いいね」だけで終わらせない**
「わかります！」「私も同じです」の一言でいい。テキストで返すことが重要。

**② 自分の体験を1文添える**
「私も最初の2ヶ月は収益ゼロでした」のように、自分の経験を短く足す。読んだ人が「この人、詳しそう」と思ってプロフィールを見に来る。

**③ 同ジャンルの投稿者のリプ欄に集中する**
「副業」「AI副業」「会社員副業」で投稿している人のコメント欄に入る。その投稿を見ている人たちは、全員あなたの潜在フォロワーだ。

### 1日のリプ返信ルーティン（10分でできる）

```
① 「副業」「AI副業」で検索して最新投稿を5件開く
② 各投稿のコメント欄に自分の体験を1〜2文で返信する
③ 返信してきた人には必ず返す（会話を続ける）

これだけ。毎日10分続けるだけで、1ヶ月で数十〜数百人増える。
```

## 1,000フォロワー達成後：プロフィールでnoteに誘導する

フォロワーが増えてくると、知らない人があなたのプロフィールを見に来るようになる。

**ここが唯一の「宣伝の場所」だ。**

投稿では宣伝しない。プロフィールだけに誘導リンクを置く。これが「売れる導線」の鉄則だ。

### 効果的なプロフィール文の構成

```
【名前】ゆうき｜AI副業会社員
【肩書き】30歳会社員 → Claude Codeで月5万円の副収入
【実績】3ヶ月で64,200円｜有料記事31部販売
【一言】深夜と土日だけで稼ぐ方法、全部noteに書いてます
【リンク】↓ 今だけ980円（値上げ予定）
```

**ポイントは「数字」と「限定感」の2つだ。**

「月5万円」「31部」という数字がリアリティを生む。「今だけ980円（値上げ予定）」という一言が、迷っている人の背中を押す。

## Threads → note → 購入の完全な導線

```
STEP1：毎日リプ欄に返信する（10分/日）
          ↓
STEP2：フォロワーが自然に増える
          ↓
STEP3：プロフィールを見に来た人がnoteリンクをクリックする
          ↓
STEP4：無料部分を読んで「続きが気になる」と思う
          ↓
STEP5：980円を払って有料部分を読む
```

投稿で宣伝しない。リプで信頼を積む。プロフィールで誘導する。

この順番を守れば、「買って」と一言も言わずに売れる仕組みができる。

## フォロワー数別のやることリスト

| フォロワー数 | やること | やらないこと |
|---|---|---|
| 0〜300人 | リプ返信に集中・自己投稿は週3〜4回 | noteの宣伝 |
| 300〜1,000人 | 投稿の質を上げる・プロフィール最適化 | 毎投稿でリンクを貼る |
| 1,000人〜 | 週1回だけnote記事をさりげなく紹介 | 焦って売ろうとする |

**1,000人を超えた後も、宣伝は週1回だけ。** それ以外の投稿は引き続き「信頼を積む」コンテンツにする。その比率が崩れた瞬間、フォロワーが離れ始める。

# 第5章：図解・構造化で「有料にして当然」のコンテンツにする

## なぜ図解が売れる記事を作るのか

同じ情報量の記事が2つあるとき、人は必ず「図解あり」のほうを選ぶ。

視覚的にわかりやすい記事は「ちゃんと考えて作られている」という信頼感を生む。その信頼感が、Threadsで興味を持ち、無料部分を読み、980円を払う——という流れの最後の一押しになる。

## Claude Codeで図解のアイデアを出す

```
以下の記事の内容を図解するとしたら、どんな図解が効果的ですか？

[記事の目次または本文の概要]

以下の形式で提案してください：
1. 図解のタイトル
2. 図解の種類（フローチャート/比較表/ステップ図/マトリックス）
3. 図解に含める要素（5〜7項目）
4. この図解がなぜ読者の理解を助けるか
```

## 私が使っている図解パターン3つ

**① Before/After比較図**
「Claude Codeを使う前／後」の変化を視覚化する。読者が「3ヶ月後の自分」をイメージしやすくなる。

**② ステップ図（左から右へ）**
手順を横並びに表示。「今自分はどこにいるか」が一目でわかり、挫折率が下がる。

**③ 収益モデル図**
「1記事×単価×月間販売数 ＝ 月収」を視覚化。具体的な数字が入ると信頼度が跳ね上がる。

## 図解の作り方（コスト0円）

無料ツール「Canva」を使う。

1. Canvaでアカウント作成（無料）
2. 「インフォグラフィック」テンプレートを選択
3. Claude Codeが提案した要素を当てはめる
4. PNG形式でダウンロードしてnoteに貼り付ける

1つの図解を作るのに15〜20分。この手間が記事の「見た目の価値」を2倍にする。

# おわりに：Threadsで一緒にやっていこう

3ヶ月前、私は「なんか副業しなきゃ」と焦っているだけの会社員だった。でも、Claude Codeという「実務をこなすAI」と出会い、実際に手を動かしたことで、副収入だけでなく「最新技術を使いこなしている」という自信を手に入れた。

今、多くの人がChatGPTのブラウザ画面を眺めて止まっている。その横を、Claude Codeを動かしながら走っていこう。

**Threadsで「ゆうき@AI副業会社員」をフォローしてほしい。**

毎日、AI副業のリアルな進捗・失敗・発見を投稿している。コメントをもらえると、次の記事のネタになる。「記事を読んだ」「やってみた」「ここで詰まった」、どんな反応でも嬉しい。
