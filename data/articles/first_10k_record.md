# 第1章：最初の1万円を阻む「3つの壁」と全部の越え方

## なぜ「最初の1万円」が一番難しいのか

副業で稼ぐ人と稼げない人の差は、スキルでも才能でもない。

**「3つの壁」を越えたかどうか**だ。

多くの人はこの壁の存在を知らないまま闇雲に動き、消耗して諦める。

### 壁①：テーマ選定の壁

「何を書けばいいかわからない」——これが最初の壁だ。

書きたいことを書いても売れない。売れるのは「誰かが今、困っていること」を解決するコンテンツだけだ。

最初の1万円まで、平均で2〜3ヶ月かかる。この期間に成果が出ないことを「失敗」と判断してやめてしまう人がほとんどだ。

# 第2章：Claude Codeで「売れるテーマ」を見つける分析術

## テーマ選定で全てが決まる

どんなに上手い文章を書いても、テーマが外れていれば売れない。

逆に、テーマさえ正しければ、普通の文章でも売れる。

これが副業2ヶ月ゼロ円から気づいた最大の学びだ。

## 毎週使っているテーマ分析プロンプト

```
あなたはnote.comのコンテンツマーケターです。

以下の条件でバズるテーマを10個提案してください。

【私のプロフィール】
・会社員（30代・非エンジニア）
・Claude Codeを使った副業・業務効率化が得意
・副業収入の実績あり

【条件】
・「会社員が実体験で書いた」感が出るタイトル
・有料記事（980〜1,980円）として成立する深さがある
・検索されやすいキーワードを含む

各テーマについて：
1. タイトル案（3パターン）
2. 想定読者
3. この記事が売れる理由
4. 目次案（5〜7項目）

を出力してください。
```

10個の提案から「自分が体験ベースで書けるもの」を3〜5個選ぶ。それが今週の執筆リストになる。

## テーマ選定の判断基準3つ

**① 自分が実体験で書けるか**
体験ゼロのテーマは薄くなる。「試したことがある」レベルが最低ライン。

**② 「悩んでいる人」が明確か**
「会社員が副業で最初の1万円を稼ぐ方法」→ 悩んでいる人が想像できる ◯
「AIの未来について考察する」→ 悩んでいる人が想像できない ✕

**③ 有料にして当然の情報量があるか**
「具体的な手順・数字・プロンプト・失敗談」がセットで提供できるテーマを選ぶ。

## 「売れる有料記事」の構成

市場の人気記事を分析してわかった、売れる記事の共通構成はこうだ。

**冒頭（無料公開部分）に入れること：**
1. 読者の悩みを代弁するフック
2. 自分の実績数字（信頼担保）
3. 等身大の自己紹介（「自分と同じだ」と感じさせる）
4. この記事で得られること（箇条書き）
5. 「今日行動しなければ」という軽い危機感

**有料部分に入れること：**
- 具体的な手順（コピペできるプロンプトつき）
- 失敗談と修正方法
- 数字で裏付けられた実績
- 読者が次のアクションを取れるまとめ

この構成通りに書くと、無料部分を読んだ人が「続きが読みたい」と自然に思う流れになる。

# 第4章：Threadsで信頼を積み、noteに自然に誘導する設計

## フォロワーが少ないうちは「売ろうとしない」

最初に気をつけるべきことが1つある。

フォロワーが少ない状態でnoteのリンクを貼っても、誰も見ていない。

**最初の目標はフォロワー1,000人。** それまでは売ることを考えなくていい。

## 最速でフォロワーを増やす方法は「リプ返信」

Threadsのアルゴリズムは「会話が生まれているアカウント」を優遇する。

つまり、自分が投稿するよりも、**他の人の投稿のリプ欄に返信する方がフォロワーが増える。**

### 1日10分のリプ返信ルーティン

```
① 「副業」「AI副業」で検索して最新投稿を5件開く
② 各投稿のリプ欄に自分の体験を1〜2文で返信する
③ 返信してきた人には必ず返す（会話を続ける）
```

効果的なリプの書き方：
- 「いいね」だけで終わらせない
- 自分の体験を1文添える（「私も最初はゼロでした」）
- 同ジャンルの投稿者のリプ欄に集中する

## 1,000フォロワー後はプロフィールで誘導する

投稿では宣伝しない。**プロフィールだけにリンクを置く。** これが鉄則だ。

プロフィール文のテンプレート：

```
【名前】ゆうき｜AI副業会社員
【肩書き】スキルゼロ会社員 → Claude Codeで月○万円の副収入
【実績】○ヶ月で累計○万円｜有料記事○部販売
【一言】深夜と土日だけで稼ぐ方法、全部noteに書いてます
【リンク】↓ 今だけ980円（値上げ予定）
```

「数字」と「限定感」の2つがあれば、初めて見た人でも行動する。

## フォロワー数別のやることリスト

| フォロワー数 | やること | やらないこと |
|---|---|---|
| 0〜300人 | リプ返信に集中・自己投稿は週3〜4回 | noteの宣伝 |
| 300〜1,000人 | 投稿の質を上げる・プロフィール最適化 | 毎投稿でリンクを貼る |
| 1,000人〜 | 週1回だけnote記事をさりげなく紹介 | 焦って売ろうとする |
